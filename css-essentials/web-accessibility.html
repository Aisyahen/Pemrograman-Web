Web Accessibility (A11y) with CSS

Proyek ini dirancang secara khusus untuk memenuhi pedoman WCAG 2.1 (Web Content Accessibility Guidelines). Setiap elemen visual dan interaktif telah disesuaikan agar ramah bagi pengguna pembaca layar (*screen reader*) maupun pembaca yang bergantung pada navigasi *keyboard*.

Standar Aksesibilitas yang Diterapkan:

  • High Contrast Ratio: Teks dan latar belakang memenuhi standar rasio kontras AAA (> 7:1).
  • Focus Visible: Indikator fokus warna kuning terang yang sangat jelas saat menggunakan tombol Tab.
  • Semantic HTML & ARIA: Penggunaan tag HTML5 (`main`, `header`, `label`) dan atribut ARIA yang tepat.
  • Screen Reader Friendly: Menyediakan tautan *Skip Link* untuk melompati navigasi.
