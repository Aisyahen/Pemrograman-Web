Sass / SCSS Workflow

Dasar-Dasar Preprocessor Sass

Proyek ini mendemonstrasikan efisiensi penulisan CSS menggunakan Sass/SCSS. Struktur sintaksis lebih bersih, modular, dan dapat dikelola dengan mudah pada skala besar.

1. Variables

Menyimpan nilai warna, font, dan ukuran secara terpusat.

2. Nesting

Menyusun hirarki selektor secara rapi ala BEM (Block Element Modifier).

3. Mixins

Fungsi reutilisasi kode untuk tata letak dan bayangan.

4. Color Operations

Manipulasi tingkat kecerahan dan transparansi warna secara otomatis.
